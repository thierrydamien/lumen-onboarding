<!-- Inter, served from this site rather than Google's font CDN.
     WHY: every client's browser used to make two extra calls to Google before the
     page could paint, handing Google their IP address. The one advantage that
     used to justify that (a shared cross-site font cache) disappeared when
     browsers partitioned their HTTP cache in 2020, so it bought nothing.
     These are the exact woff2 files Google served, with Google's own
     unicode-range split preserved: a typical client downloads only the 47 KB
     latin file, and latin-ext (85 KB) is fetched ONLY if a page actually renders
     Polish/Turkish/Czech characters — e.g. a client's brand name.
     One @font-face per subset covers every weight because these are VARIABLE
     fonts (verified by measuring 400/600/700/800 render distinctly), so the
     wordmark's 800 costs nothing extra.
